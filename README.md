# HandDim updates

This repository hosts the official signed update feed and downloadable HandDim releases.

HandDim is a macOS menu bar app that sets the built-in display brightness to zero with a hand gesture.

- Purchase: https://handdim.lemonsqueezy.com
- Update feed: https://raw.githubusercontent.com/azizedelam/handdim-updates/main/appcast.xml

Update packages are signed and notarized before publication. HandDim verifies update signatures before installation.

The initial feed contains no downloadable release. Releases will be added after installation and update testing is complete.
